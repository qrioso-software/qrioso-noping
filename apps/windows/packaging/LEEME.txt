Qrioso NoPing - build de desarrollo
==================================

1. Ejecuta install.ps1 como Administrador.
2. Abre Qrioso NoPing desde el acceso directo del escritorio.
3. Para removerlo, ejecuta uninstall.ps1 como Administrador desde este paquete.

Este build todavía no contiene el data plane WireGuard/WFP. Sirve para validar
la UI, el Windows Service y el proceso de instalación durante el desarrollo.
